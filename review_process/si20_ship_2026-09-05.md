## 4. Judgment calls for the author (nothing below was changed)

1. **df_a over-count from the absorbed ringer terms.** reghdfe counts the added slopes in df_a, so
   V/SE/t/p/CI on EVERY row (att rows included) scale by df_r_old/df_r_new: +1 df on the plain-basic
   default path (0.035% at N = 1728; V x1.115 on dta_tiny with ~9 residual df), +4-6 df under basic
   byX + lattice where the terms are redundant with the already-absorbed byX#lattice slopes (V
   x1.0028..1.0050; joint p in the 3rd digit). Options: accept (the non-lattice basic path already
   carried the +1); or skip the null/lattice terms when a byX term is present (restores pristine SEs
   on reghdfe but re-exposes the R4 reg-refit failure, where reg dropped the byTreated ringer and
   re-introduced the anchor).
2. **`ext_san_input_missing` crosses a pre-existing knife edge.** binary_balanced [aw] controls(c.x1)
   cluster(person_id) contreat(dose) basic lattice(custom_lattice), 9 planted missings: the fixed
   build posts NO e(V) (all-zero VCV caution; 36 person clusters against ~100 parameters), att points
   identical, ame moved by the base slope. Nine variants show the all-zero-VCE state exists on both
   builds and fix 1's extra absorbed slopes push three of them across it. Observable failure, not
   wrong numbers. The R4 refit cannot rescue it (gated on the cluster being at the cell level).
   Candidate: widen the R4 refit trigger to any all-zero VCV with a single cluster variable and no
   fe()/ccc_absorb.
3. **permute(shuffle) + contreat basic with a real dose effect mis-centres the pre-ame null.** On
   dta_cont's y the fixed build's e(perm_offcentre) still lists pretreatment_ame / ES_ame_pre2 /
   pre1 (bands [-0.80, -0.06]); on a null outcome and on the dense fixture it is empty. Mechanism:
   under shuffle the fake control group includes truly-treated units whose post rows carry the real
   dose effect, so the pooled basic base slope exceeds the truth and the fake pre-ame goes negative
   (att pre rows are immune). The off-centre guard and perm_precaveat catch it; the pristine build
   hid it behind the +2 anchor. Pre-existing in kind, exposed by the fix.
4. **V_es_ame now carries the base slope's variance.** V_es_ame(fixed) = V_es_ame(pristine) x (df
   ratio) + Var(base slope) x J (residual <= 2.4e-13; c = 0.0017857 on the flagship = the ticket's
   Var(anchor)). This is the correct inference for a dose effect measured relative to the partialled
   baseline; it explains x_within's rank-1 V_es_ame (pristine's was degenerate).
5. **`test_refmargin.do` runtime** is ~24 min per run (cert timeout 3600 s); dominant cases are the
   unit-level-i covars fixtures (B1/B3/B4/B7/B8, 90-175 s each). Trim or keep.
6. **Adjacent, unchanged:** under unconditionalse/customvce the fe() list is passed bare to reg
   (~line 1480): a linear id term, so every "reg twin" identity had to avoid fe() or use fe(i.var).
7. **Pre-existing, out of scope (D):** permute()'s fast-mode default sets fastnose, so the R6
   ame-void gate (fastnose == "") never engages and structural-zero ame rows display 0 / p = 1 /
   [0, 0] with only the degenerate-distribution caution.
