## What the differences were (all documented)

- **Large, deliberate corrections** (summary-stats control row B1, sub-sample IQRs B2,
  `e(ll)` under impvalues B4, B16 adversarial reference planting, mint sentinel onsets
  A15, IM degeneracy guard A16/A17, gen-double unit/onset codes A10/A11, cfx width
  truncation B7, extended missings B9, e(sample) weight base B10, E1b unconditional
  joint tests). Each fires on the configs built to trigger it.
- **Storage-noise classes** (B21 gen-double + svmat float→double): measured ceilings
  1.33e-4 (interactivecontrols regressor copies) / 2e-5 (adversarial p tails) / ≤4e-6
  (joint-test p) / ≤2e-7 (fit statistics) — all bounded in the ledger, far below any
  wrong-answer class (≥1e-2).
- **Error-contract changes by design**: 66 rc pins, each verified empirically (e.g.
  string cluster r109 on BOTH builds — the surface-diff prediction of old-runs-clean was
  wrong; fractional onsets 0→459; lattice misuse silent→198; B23 false positives cured).

  (V present); new applies real trends and omits e(V) — exactly the documented tcen
  behavior. At 4-digit years the hdfe path agrees within 1e-10 (better than expected).

## New findings surfaced BY the suite (tickets for the author — no action taken)

1. **v1.3 pwsgs maxdouble artifact (old-build defect, already structurally fixed in
   HEAD).** On repeated-cross-section + pweight + subgroups configs
   (`ext_cov10_rcs_pweight_ddd_*`, `ext_cov10_rcs_twoway_cluster_*`), v1.3 stores
   missing SG-pairwise cells as 8.99e+307 (missing-through-float svmat) and returns
   degenerate-SE-amplified junk (t-stats ~1e9, one negative SE −8.9e−16); HEAD returns
   clean values via the E1 posted-pwcompare rewrite. Never previously catalogued.
2. **`ccc_absorb()` is broken on BOTH builds**: the regression completes, then a bare
   "invalid syntax" r198 fires in the margins phase (`cov_ccc_absorb`,
   dta_s_covars). The option had zero test coverage anywhere before this suite. Needs a
   root-cause pass (also errs combined with `coarsecohortcontrols()`).
3. **o.-omission-marker naming fragility, RCS instance** (`ext_contract10_rcs_factor_fe`):
   NEW errs r198 "5o. invalid name" on Stata 19 where OLD escapes by omission-pattern
   luck; the colleagues' Stata 17 run of OLD hit the same error (their msg_old proves
   it). Same family as the known o.-marker/truerow ticket — this adds a realistic
   reproduction path (repeated cross-section + factor fe).
4. **Environment-dependent rc pins vs the bundle's Stata 17 records**:
   `ext_path10_ppml_separation` (bundle old rc 503; here rc 0 on both — newer ppmlhdfe
   handles the separation), and the rcs_factor_fe case above. Pinned to OUR environment
   with notes.
5. **`ext_contract10_if_outside_negative`**: new honors the user `if` (B23 fix) and then
   correctly refuses r322 because the exclusion empties an entire cohort (old died on
   the B23 false-positive assert instead). Working as intended; recorded because the
   rc pair (411→322) is non-obvious.

## Residual gaps (honest list)

- `cov_icbad` did **not** reach the B21(b) engineered-collinearity trigger (levels ~1e6
  are float-representable); old ran clean and matched. A future data tweak (levels ~1e8)
  would pin that documented catastrophic class old-side.
- `trig_singleton` came out **parity** (both builds drop the same 7 obs and agree) — the
  B10 divergence fires when whole cohort-period cells drop (covered by
  `trig_allest_drop`), not for these stranded singletons.
- `trig_bigcodes`: old ABORTS r461 on the YYYYMMDD grid (documented A11 abort variant);
  the silent-pooling variant (old runs with merged cohorts) is not reproduced old-side
  here — it was proven during the 8c5bfd7 campaign work.
- The colleagues' 21-case **oracle/metamorphic library** is not ported (future
  component). Their PowerShell harness, serializers, and report generators were
  deliberately dropped.
- Console output is not compared (message texts intentionally changed program-wide).
- 28 bundle cases skipped by design (3 harness self-tests, 4 pilots, 21 oracle-family).
