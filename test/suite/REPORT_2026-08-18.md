# Testing & assessment suite — certification report (2026-08-18)

Builds compared: **old** = published wooldid v1.3 (`git main`, byte-identical to the
colleagues' bundle benchmark) vs **new** = git HEAD. Environment: Stata 19 MP, macOS,
gtools present. This report covers the initial full run, the adversarial
pre-certification review, the fixes it drove, and the final certified state.

## Headline

**Every old-vs-new difference across all 448 configurations traces to a documented,
intentional fix.** Final verdicts: **133 MATCH** (zero differences at rtol 1e-10 —
including e(sample) digests, realized-sample composition, and saveplots file naming
where applicable), **245 EXPLAINED** (every difference matched a cited,
magnitude-bounded ledger row), **70 RC_EXPLAINED** (error-contract changes or identical
error parity, pinned per config), **0 UNEXPLAINED, 0 STALE, 0 UNSCOPED ledger rows,
0 provenance failures** — produced end-to-end by the orchestrator (exit 0), with
`COMPARED 448 of 448` accounting enforced.

Other components: `cert` 11/11 (the 10 targeted suites — including the upgraded
test_fastnose replay byte-comparison and the new test_s6 cleanmatrices-survival block —
plus validate-sync); `newfeat` 3/3; `battery` 29/29 bit-identical; `coverage` OK across
the option surface with clean-rc gating (allow-zero: `update`, `permprobs` only).

Scope notes: both-error parity pins assert the **return code only** (messages are out
of contract); the bounded ledger tiers are noise-vs-wrong-answer **separators
calibrated to measured ceilings** (recorded per row, several observed to be
run-varying where degenerate cells amplify ULP noise), not a forward tolerance policy —
forward regression-guarding is the rtol-0 battery's job.

## The pre-certification review (4 adversarial lenses + mutation testing)

The review reproduced real defects in the suite itself; all are fixed and re-verified:

- **The comparer could certify wrongly**: truncated dumps passed as MATCH (now: `end|`
  sentinels required); configs missing from both sides were invisible (now: universe
  accounting, `COMPARED N of M`); stale mixed-vintage dumps were compared silently
  (now: provenance uniformity enforced per side, full runs clean their dump dirs, the
  new build is staged from git HEAD — never the working tree).
- **Pass-grading was fake-able**: `grep _ALL_PASS` matched echoed header text, so even
  a failing cert/newfeat suite graded PASS — demonstrated against a mutant. Now:
  column-1-anchored result lines + `*_FAILS=` absence + fresh-log mtimes + pre-deleted
  logs, and every component's failure propagates to the orchestrator exit status.
- **Ledger bounds were up to ~30,000× looser than measured ceilings** (a 1e-3 band over
  the whole mined estimation surface). Now: ~10× measured ceilings per class, LARGE
  rows scoped to named configs, blind-spot configs explicitly labeled, missing-value
  codes decode to sentinels (a `.`→`.a` flip can never be bounded-explained), NaN
  guards, and UNSCOPED-row detection.
- **Mutation testing** (5 planted bugs in copies of the ado): 3 were caught, 2 escaped
  and drove new checks — (a) a permute rep-reuse bug passed the entire cert suite and
  was caught only by the external RI check, whose sampled path was itself unvalidated:
  the RI cross-check now externally replicates the sampled draw stream rep-by-rep
  (bitwise), enumerates an unequal-count design (60 assignments) that distinguishes the
  level-counts-fixed scheme from every wrong scheme the equal-count design cannot,
  value-validates permtstat, and band-checks permute(probabilities) frequencies;
  (b) an off-diagonal corruption of `e(V_es_att)` — the matrix that exists to feed
  HonestDiD and pretrendpower — passed everything: the new **total-variance identity**
  (s′·V_es·s = SE(att)², which holds bitwise on HEAD) now catches it (fails at 3.5e-4
  against the mutant vs a 1e-8 gate).
- **e(sample) was never compared** — now every dump carries an order-independent
  realized-sample digest (N + per-variable sums); saveplots outputs are compared by
  name (`files|`, consumed per config).
- **Coverage was counted by presence, not execution**: an option "covered" only by an
  erroring config now flags ERR-ONLY; dead allow-zero exemptions fail the check.
- **Cost claims were ~10× off**: the full run measures ~20–30 minutes, not "hours" —
  docs recalibrated (this matters: it makes the full suite a routine checkpoint tool).

## Realistic-data coverage (new this revision)

`dta_s_admin`: 2,000 FIPS-style counties × 2005–2019, unequal cohorts
(2009/2012/2015/never at ~40/25/10/25%), ~8% unbalanced entry/exit, lognormal
population weights spanning 300–10M, scattered regular-missing outcomes,
near-collinear controls, rare-count outcome, region subgroups, state clusters.
Eleven `adm_*` configs give first-ever coverage of `customvce(cluster)`,
poisson+pweight, clean factor-variable `fe()`, subgroups×summarystats,
unconditionalse+pweight, the saveplots×subgroups filename pin, and a unit-level-`i`
subsample run. All MATCH or fire cited ledger rows.

Two findings from realistic scale (tickets, no action taken):
- **T-A: unit-level `i` at 2,000 units exits r(907) mid-run** (the estimator's
  cell-dummy grid is levels(i)×periods ≈ 22,500 > maxvar 20000). Correct usage at that
  scale is cohort-level `i`, but the failure is cryptic and late — a pre-flight size
  hint ("your i×relyr grid implies ~N dummies") would help. (One config, `adm_pois_pw`,
  also surfaced rc 3598 under the unit-level design before restructuring.)
- **T-B: cohort-level `i` with a finer subgroup variable is refused r(459)** by the
  e5445c4 split-unit gate on new, where **old ran silently** — correct new behavior,
  pinned as `adm_sgsplit`, worth a help-file sentence (subgroups must be constant
  within `i`, including when `i` is a cohort id).

- `cov_icbad` does not reach the B21(b) engineered-collinearity trigger (levels ~1e6
  are float-representable); a ~1e8 variant would pin that class old-side.
- `trig_singleton` is genuine parity (both builds drop the same 7 obs — now verified by
  the e(sample) digest, not inference); the B10 divergence fires via `trig_allest_drop`.
- `trig_bigcodes` pins the old-build r461 abort variant; the silent-pooling variant was
  proven during the 8c5bfd7 campaign work.
- The colleagues' oracle/metamorphic library is not ported (future component); console
  text is not compared; `.gph` content is not compared (names only).
- The RI sampled-mode check pins the current drawing scheme and RNG consumption under
  its seed — a legitimate reimplementation of the sampler will fail it and requires
  updating the external replication loop (documented in the do-file).
- The pre-window analog of the V_es total-variance identity does not hold (the
  reference consumes pre horizons — observed 3.6e-2 on HEAD); left as an uncounted
  info line with the reason documented.
